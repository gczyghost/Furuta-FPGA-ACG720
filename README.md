# Furuta FPGA / ACG720

基于高云 ACG720 的无刷直驱旋转倒立摆实时控制系统。B114 显示版固件与配套 GUI95 的核心工程源码。

- `fpga/`：40 个 SystemVerilog 文件、CST/SDC、7 份 ROM、可直接执行的 Gowin 构建入口。
- `gui/`：完整正常运行源码、固定依赖、PyInstaller 打包入口、第三方许可。
- `mechanical/`：V8 总装与全部零件、STEP/STL 和 BOM。
- `pcb/`：RevF 嘉立创 EDA 专业版原生工程、同批制造导出及 RevF/R1 正反面设计图；R1 反面已镜像，R1 为洞洞板装配参考。

各子目录 `README.txt` 提供构建或打开方法。控制核心 25 MHz、外设 50 MHz。S0-S4 支持在线/离线切换、清错、起摆、下落及单次演示；板载 LED 和 A/P 角度轮显。

本仓库不包含预编译位流、EXE、工具链、内部调度/验收脚本或现场标定。赛事代码 RAR 包另含固件与 Windows 程序。
固件为 SRAM 配置，掉电需要重新下载。实机使用前须确认器件、机构状态及本机标定；不得套用其他机构参数。板端保护不应被绕过。

源文件与已成功构建 B114 的必需输入一致，目录整理经过静态依赖审查，未为上传重新综合/布局布线；重新构建不承诺位流逐位相同。GUI 保留正常产品依赖，移除仅由旧测试入口引用的检查模块。
机械保留全部零件；若 SolidWorks 提示历史路径缺失，请将引用定位到同包 `parts/`，也可直接查看 STEP。

第三方代码与运行依赖遵循各自许可；相关文本保留于 `gui/third-party-licenses/`。本项目自有内容目前公开供审阅，暂未授予开源许可证。
